The coefficient of variation (CV) is a standardised measure of dispersion, that can be used to compared the dispersion of variables measured in different scale:

Descriptive statistics vs parameters

Descriptive statistics are calculated from the observations (the data).

eg: The trees that we can measure in a forest plot are a sample of the population of the trees in the considered forest. We can calculate the mean diameter of this sample.

The observations are a sample of a theoretical population that we don’t measure. The theoretical population can be described by its parameters, that are not measured.

eg: The mean diameter of the population of trees in the considered forest is a parameter. It cannot be measured but can be estimated.

taht’s what we want to do with the stats, use observations to understand the theoretical population

Statistical distributions

We can use statistical distributions to represent the distribution of the values of the variable in the theoretical population.

A statistical distribution (also called probability law) is a function that associates a probability with each possible value of a random variable.

Statistical distributions

Here, the probability that \(x \in [-1, 1]\) is equal to the blue area, which is the integral of the density function between -1 and 1.

The density function does not give the probability of being equal to a value, as for a continuous variable, this probability would be null.

Uniform distribution

\[\mathcal{U}(a, b)\]

\(a\) and \(b\) are the two parameters of an uniform distribution. \([a, b]\) is the range of possible values (so a is the minimum value and b the maximum value)

e.g. for \(\mathcal{U}(2, 5)\)

a < x < b : equi proba

x > b: proba nulle

Normal distribution

\[\mathcal{N}(\mu, \sigma^2)\] The two parameters of a normal distribution are:

  • \(\mu\) is the mean

  • \(\sigma^2 > 0\) is the variance, so \(\sigma\) is the standard deviation

💡 The normal distribution is also called Gaussian distribution.

Centred reduced normal distribution

If \(x \sim \mathcal{N}(\mu, \sigma^2)\)

then \(z = \frac{x - \mu}{\sigma}\) follows a centred reduced normal distribution:

\(\chi^2\) test

We can then perform a \(\chi^2\) test, to test the independence of the two categorical variables.

H0: the variables are independent.

We use the function chisq.test on the contingency table (not on the percentage):

res_chi2 <- chisq.test(tab_abd)
res_chi2

    Pearson's Chi-squared test

data:  tab_abd
X-squared = 155.6, df = 9, p-value < 2.2e-16

The result shows the following values:

  • X-squared is the value of the \(\chi^2\) statistics, which is a “distance” between the observed occurrences and the expected ones if the variables were independent.

  • df is the number of degrees of freedom

  • p-value is the probability to get such a X-squared value under the assumption of independence. Here the p-value is very low, so we can reject the null hypothesis of independence.

for a χ² test of independence on a contingency table is:

df = (nb row -1) * (nb col - 1) = (10-1) * (2-1) = 9

the test concludes that the occurence of these 10 genus depends on the plot

\(\chi^2\) test

Testing if two groups differ considering a quantitative variable: the t-test

Let’s work with the Nouragues tree data

We will focus on two genus: Dicorynia and Protium:

# one dataset with both genus
dt_sub <- dt_HD %>% 
  filter(genus %in% c("Dicorynia", "Protium"))

# one dataset per genus
d_Dico <- filter(dt_sub, genus == "Dicorynia")
d_Prot <- filter(dt_sub, genus == "Protium")

We do both a common dataset and two dataset per genus

Do the two genus differ in height?

Let’s explore this graphically:

dt_sub %>% 
  ggplot(aes(x=genus, y=H)) + 
  geom_boxplot()

yes, it seems so

Are the distribution of height in both genus normal?

An assumption of the t-test is that the data are normally distributed.

To decide which test to use, we first check the normality of the distribution with a Shapiro-Wilk test, using the function shapiro.test

H0 of the Shapiro-Wilk test: the distribution is normal

shapiro.test(d_Dico$H)

    Shapiro-Wilk normality test

data:  d_Dico$H
W = 0.9642, p-value = 0.6307
shapiro.test(d_Prot$H)

    Shapiro-Wilk normality test

data:  d_Prot$H
W = 0.98494, p-value = 0.8708

The tests are non-significant, so they don’t reject the hypothesis of normality. We can consider the two distributions as normal.

Are the distribution of height in both genus normal?

We could also check the normality graphically with normal Q-Q plot:

qqnorm(d_Dico$H)
qqline(d_Dico$H)
qqnorm(d_Prot$H)
qqline(d_Prot$H)

The points fall reasonably on the diagonal line, we can consider the data as normally distributed.

t-test

As the two distributions are normal, we can do a t-test using the function t.test:

A t-test test the equality of means of two groups: H0: equality of the means

t.test(dt_sub$H ~ dt_sub$genus)

    Welch Two Sample t-test

data:  dt_sub$H by dt_sub$genus
t = 4.7119, df = 21.786, p-value = 0.0001086
alternative hypothesis: true difference in means between group Dicorynia and group Protium is not equal to 0
95 percent confidence interval:
  6.675884 17.183090
sample estimates:
mean in group Dicorynia   mean in group Protium 
               31.75000                19.82051

The result is significant, so we can reject the null hypothesis that the means of both groups are equal and conclude that the two genus differ in height.

💡 The result indicates that we performed a Welch t-test, which doesn’t assume homoscedasticity (equality of variance). If we want to run a t-test assuming homoscedasticity, we need to use the argument var.equal = TRUE.

the Welch modification is done because it handle better unequal variances and unequal sample size => here clearly heterosceasticity (non homogeneity of variance)

the test tell us

  • the estimated mean per group

  • that the difference between the two is between 6.67 and 17.18 meters (95% confidence)

Wikcoxon rank test

We can do a Wilcoxon rank test, which is the non-parametric equivalent to the t-test, using the function wilcox.test:

💡 A non-parametric test is a test that does not make any assumption regarding the distribution of the observations.

The test assume all values to be different, but there are some ties (equal values) so the p-value is approximates => here very small so OK

Testing difference between more than two groups: the ANOVA

Analysis of variance: ANOVA

With the t-test, we tested the difference between two groups.

If we have more than two groups, we use the ANOVA.

The ANOVA compares the variation within groups with the variation between groups.

H0: all the observations come from populations with a same mean.

Do the height of several genus differ?

We extent the analysis done on Dicorynia and Protium to more genus: let’s consider the 10 more abundant genus.

Let’s start with a graphical exploration:

ggplot(dt_sub10, aes(x=genus, y=H)) + 
  geom_boxplot()

ANOVA

We perform the ANOVA using the function aov:

H_aov <- aov(H ~ genus,
             data = dt_sub10)
summary(H_aov)

The test is significant, meaning that the groups differ.

Checking the model assumptions

The ANOVA assumes homoscedasticity, meaning a constant variance of residuals across groups.

We check this graphically by plotting the residuals against the fitted values (the estimated mean for each group):

plot(H_aov, which = 1)

There is no strong pattern.

The residuals are distributed around 0 in a similar way for each groups.

We can consider that the assumptions of homoscedasticity is respected.

the function plot, when used on the results of a statistical test, provides several very usefull graphs to diagnose the test

Checking the model assumptions

The ANOVA assumes that the residuals are normally distributed.

We check this graphically with a Q-Q plot:

The points are mostly on the diagonal.

We can consider that the assumption of normality of the distribution of the residuals is respected.

What to do if the assumptions of the ANOVA are not met?

If the assumption of normality of the residuals is not met, we can:

  • Perform a Kruskal-Wallis test (non parametric) using the function kruskal.test

  • Transform the continuous variable (log, sqrt…)

  • Perform a generalised linear model (GLM)

If the assumption of homoscedasticity is not met, we can perform a Welch’s ANOVA using the function oneway.test

Covariance and correlation

Covariance

We have seen that the variance of a variable x is the mean of squared deviations from the mean:

\[\sigma^2_x = \frac{\sum_{i=1}^n (x_i-\bar{x})^2}{n}\]

The covariance between two numerical variables x and y is the mean of the product of the deviations of x and y from their respective mean:

\[cov_{xy} = \frac{\sum_{i=1}^n (x_i-\bar{x}) \times (y_i-\bar{y})}{n}\]

Covariance

We use the function cov to get the covariance between two variables.

Let’s test this with the iris data set, which you graphically explore in a last exercise. We focus on the species versicolor:

data(iris)
iris <- as_tibble(iris)
iris_vers <- iris %>% filter(Species == "versicolor")
cov(iris_vers$Petal.Length, iris_vers$Petal.Width)
[1] 0.07310204

⚠️ The unit of the covariance is the product of the unit of x and of y…

is this high? low? hard to say…

Correlation of Pearson

To help with the interpretation of the covariance, we standardise the covariance by the product of the standard deviations.

This is the coefficient of correlation of Pearson, which is between -1 and 1:

  • a coefficient = -1 (respectively 1) means that the variables are perfectly negatively (respectively positively) correlated

  • a coefficient = 0 shows an absence of correlation

We use the function cor to get the correlation between two variables (the default method is Pearson correlation).

cor(iris_vers$Petal.Length, 
    iris_vers$Petal.Width)
[1] 0.7866681

There is a strong positive correlation.

So here strong positive correlation

Correlation of Spearman

Pearson correlation makes the hypothesis that the relationship is linear.

If this is not the case, we can use the rank correlation of Spearman, by specifying the method:

cor(iris_vers$Petal.Length, iris_vers$Petal.Width,
    method = "spearman")
[1] 0.7870096

here, not much difference

Test of correlation

To test if the correlation is significant, we do a test of correlation with the function cor.test:

cor.test(iris_vers$Petal.Length, iris_vers$Petal.Width,
         method = "pearson")
