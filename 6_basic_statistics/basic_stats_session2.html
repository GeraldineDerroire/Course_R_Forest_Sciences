Structure of a linear regression

A linear regression is a mathematical model of the relationship between:

  • A response variable, also called dependent variable

  • One or several explanatory variables, also called predictors or independent variables

Relationship between D and H

We want to model the relationship between D (the explanatory variable) and H (the response variable).

As our model has only one explanatory variable, it is called simple linear regression.

We want to model a tree dimension by another tree dimension. This is an allometric model. Allometric models are often used to predict a variable difficult to measure from a variable more broadly available.

ex of an allometric model

Theory

\[y = \alpha + \beta \times x + \epsilon\]

  • y is the response variable

  • x is the explanatory variable

  • \(\alpha\) is the intercept (the mean of Y when X = 0)

  • \(\beta\) is the slope of the relationship between X and Y

  • \(\epsilon\) is the residual of the model. \(\epsilon \sim \mathcal N(0, \sigma^2)\)

\(\alpha\), \(\beta\) and \(\sigma\) are the parameters of the model

The model can also be written:

\[y \sim \mathcal N(\alpha + \beta \times x, \sigma^2)\]

who want to write the equation of the model we want to fit on the blackboard?

Theory

\[y \sim \mathcal N(\alpha + \beta \times x, \sigma^2)\]

The model predicts a probability density of Y for any value of X (in red) normally distributed around the regression line (in black).

Source: E. Marcon

  • The mean value of Y for any value of X is the black line : \(\mu = \alpha + \beta \times x\)

  • The predicted probability density of Y are represented by the red dots: they are normally distributed around the mean with a variance \(\sigma^2\)

read the fig as in 3D

Fitting a simple linear regression

We use the function lm to fit a linear regression:

mod_dh_1 <- lm(H ~ D, # formula
               data = dt_nou)

Syntax of the formula:

  • response variable ~ explanatory variable(s)

  • the intercept is implicit so H ~ D is equivalent to H ~ 1 + D

If we don’t want an intercept, we have to write H ~ 0 + D. The regression will go through the origin (0,0).

Null model : a model without explanatory variable F-test for only one single explanatory variable is the same as the test for the explanatory variable

Coefficient of determination

R2 is the coefficient of determination: it represents the proportion of variance of the response variable explained by the model. The closer R2 is to 1, the greater the explanatory power of the model. R2 therefore reflects the goodness of fit of the model.

Adjusted R2 penalise R2 by the number of explanatory variables (not relevant when there is just one explanatory variable).

R2 and p-value

  • The p-value indicates the significance of the effect of the explanatory variable: this effect can be small yet highly significant => a small p-value is particularly important for hypothesis testing.

  • The R2 indicates the goodness of fit (how well the model fits the observed data) => a high R2 is particularly important for prediction.

Confidence interval

The confidence interval is the interval of confidence of the mean predicted value of y (so of \(\mu\)).

To calculate it, we can use the function predict_response from the package ggeffects. The default give the confidence interval:

# Get the prediction (default arguments gives the confidence interval)
preds_conf <- predict_response(mod_dh_1, # model used for the prediction
                        terms = "D") # explanatory variable

Prediction interval

The prediction interval includes the uncertainty of the predicted mean (like the confidence interval) and the variability of individual prediction by taking into account the residual variance \(\sigma^2\). It is therefore wider than the confidence interval and contains most of the observations.

To calculate it, we can use the function predict_response, with the argument interval = “prediction”:

# Get the prediction with prediction interval
preds_pred <- predict_response(mod_dh_1, # model used for the prediction
                        terms = "D", # explanatory variable
                        interval = "prediction")

Model validation

We need to check the model assumptions:

  • independence of observations

  • linearity of the relationship between response and explanatory variables

  • independence of the residuals

  • constant variance of the residuals (homoscedasticity)

  • normality of the residuals

Independence of observations

An linear regression assumes that all observations are independent.

This is related to the study design: when observations are grouped, they are not independent (e.g. several observations on a same site, on a same individual, in a same year…).

A graph of residuals against the suspected grouping variable (site, …) can help detect possible problems.

we’ll see later what to do then

Influential observations (Cook’s distance)

plot(mod_dh_1, which = 4)

Cook’s distance measures how much the fitted values would change if that single observation were removed — combining both its leverage (how extreme its x-value is) and the size of its residual, so it flags observations that are influential.

⚠️️ Some observations are highly influential.

for cook distance, several rule of thumbs

  • D should be < 1

  • D should be <4/n

Variable transformation

Our model has problem of linearity and high influence of some observations.

💡 A transformation of variables may help, let’s try to take the log of D and H:

\[log(H) = \alpha + \beta \times log(D)+ \epsilon\]

which is equivalent to

\[H = \alpha'D^\beta \times e^{\epsilon}\] with \(\alpha' = e^{\alpha}\)

Here the error is multiplicative.

This is a classical allometric model: it predicts that the height of the tree will increase less rapidly for trees with bigger DBH, which is consistent with what we expect.

equivalent because \(log\big (\alpha'D^\beta \big) = log(\alpha') + \beta \times log(D)\)

Data transformation

Why transform the data?

  • linearise a non-linear relationship (eg: quadratic relationship \(y = \alpha + \beta_1 \times x + \beta_2 \times x^2\), square root or log-transformation…) which can be meeting our ecological hypothesis better

  • improve normality and homoscedasticity of the residuals (eg: square root of log-transformation…)

  • reduce the influence of outliers (eg: log-transformation…)

Multiple linear regression

Equation

A multiple linear regression is a regression with several explanatory variables:

\[y \sim \mathcal N(\alpha + \beta_1 \times x_1 + \beta_2 \times x_2 + ... + \beta_n \times x_n, \sigma^2)\] which we can also write:

\[y \sim \mathcal N(\alpha + \sum_{i=1}^n\beta_n \times x_n , \sigma^2)\] 💡 Explanatory variables can be numerical or categorical.

Standardising explanatory variables

To compare the effects of the explanatory variables, we can (but we don’t necessarily need to) standardise them using the function scale:

hills <- hills %>% 
  mutate(dist_sd = as.numeric(scale(dist)), # scale return a matrix so need to transform

Collinearity

For multiple linear regression, we need to check the absence of collinearity of the explanatory variables.

If an explanatory variable is a linear combination of the other, this impedes the model fitting.

We can look at the correlation between variables:

cor(hills$dist_sd, hills$climb_sd)
[1] 0.6523461

We can also check the VIF (variance inflation factor), using the function vif from the package car:

vif(mod_hills2)
 dist_sd climb_sd 
1.740812 1.740812

⚠️ If the VIF of some explanatory variables is above 10 (or even 5), some explanatory variables should be excluded from the regression.

Interaction

Multiple linear regression can include an interaction term to test if the effect of an explanatory variable depend of the value taken by another explanatory variable:

Here, the effect of \(x1\) on \(y\) (the slope of the relationship between \(x1\) and \(y\)) depends on the value taken by \(x2\).

Interaction

The model with a interaction is:

\[y = \alpha + \beta_1 x_1 + \beta_2 x_2 + \beta_{12} x_1 x_2 + \epsilon\]

which is equivalent to

\[y = \alpha + (\beta_1+\beta_{12} x_2) \times x_1 + \beta_2 x_2+ \epsilon\]

and

\[y = \alpha + \beta_1 x_1+ (\beta_2+\beta_{12} x_1) \times x_2 + \epsilon\]

\(\beta_{12}\) is the coefficient of the interaction. It represent the effect of \(x_2\) on the relationship between y and \(x_1\), and the effect of \(x_1\) on the relationship between y and \(x_2\).

Model comparison

To compare several models, we can use the AIC (Akaike information criterium).

The AIC takes into account the likelihood of the model while penalising a more complex model (i.e. a model with more parameters) to avoid over-fitting.

To compare models using the AIC, they need to:

  • have the same response variable (not possible to compare a model with a transformation of the response variable with a model without transformation)

  • be fitted on the same data (so be careful with NAs)

The model with the lowest AIC is the best model (we usually consider a model difference of at least 2).

explain overfitting: when a model fit the data too closely, capturing random noise and fluctuation in addition to the true underlying pattern

What if the observations are not independent?

An linear regression assumes that all observations are independent.

When observations are grouped, they are not independent (e.g. several observations on a same site, on a same individual, in a same year…).

  • We can include the group as a categorical explanatory variable. This evaluate the effect of each group.

  • When the number of groups is too high and we are not interested in the effect of each group, we can use a linear mixed model.

Linear mixed model

Linear mixed models have a hierarchical structure.

One or more of their coefficients (the intercept or the response to explanatory variables) varies between groups j:

\[y_{ij} \sim \mathcal N(\color{crimson}{\alpha_j} + \beta \times x_{ij} , \sigma^2)\]

and this variation is modelled by a group-level distribution:

\[\color{crimson}{\alpha_j} \sim \mathcal N(\mu_{\alpha}, \sigma^2_{\alpha})\]

The group-specific intercepts \(\color{crimson}{\alpha_j}\) are not independent parameters: they are drawn from a common distribution.

NB: here we represent the effect of the group only on the intercept, but we can include this effect on the other coefficients as well.

What if the data are not normally distributed?

Some data are by nature not normally distributed, so we cannot model them with a normal distribution.

  • success/failure data (e.g: presence/absence of a species in a plot, proportion of tree browsed in a plot) can be modelled with a binomial distribution

  • count data (e.g.: number of individuals of a species in a plot, number of birds heard in a given time) can be modelled with a Poisson distribution

To know more about these distributions: see the Wikipedia pages, and the distribution zoo.

Generalised linear models

Generalised linear models (GLM) are an extension of linear models allowing different distributions of the response variable.

They have 3 component:

  • a linear predictor: a linear combination of explanatory variables

  • a distribution of individual responses around their mean

  • a link function between the predictor (defined on \(\mathbb{R}\)) and the mean response (not necessarily defined on \(\mathbb{R}\))

In the linear model seen before, the distribution is Normal and the link function the identity.

Logistic regression

The logistic regression is a GLM with a binomial distribution and a logit link function. It models a probability of success.

  • The binomial distribution \(\mathcal{B}(n, p)\) represents the number of successes when performing n independent experiment having a constant probability of success p (e.g: presence/absence of a species in a plot, proportion of tree browsed in a plot).It is a discrete distribution taking only positive integer values.

  • The logit link function links the modelled probability of success (which is between 0 and 1) to the linear predictor.

The Bernoulli distribution is a special case of a binomial when n=1.

💡 See here for a detailed explanation of the logistic regression.

logit(p) = alpha + beta_1x_1 +… beta_nx_n

avec logit(p) = log (p/ (1-p))

Poisson

The Poisson regression is a GLM with a Poisson distribution and a logarithm link function. It models the number of observations of an event in a defined sampling unit.

  • The Poisson distribution \(\mathcal{P}(\lambda)\) represents the mean number of observations \(\lambda\) in a sampling unit (e.g.: number of individuals of a species in a plot, number of birds heard in a given time).

  • The logarithm link function links \(\lambda\) (which is positive) to the linear predictor.

💡 See here and here for detailed explanations of the Poisson regression.

log(mu) = alpha + beta_1x_1 +… beta_nx_n

What about Bayesian models?

All the models we have talked about (and many more!) can be fitted in a Bayesian framework (as opossed to the frequentist one we used).

What are the advantages of a Bayesian approach?

  • it allows to quantify uncertainty (and propagate it), as we get a full distribution for each fitted parameters

  • it allows to leverage prior knowledge (previous studies or expert knowledge)

  • it is flexible (adapted to heterogeneous or incomplete data, possible to fit complex models)
